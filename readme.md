## 🧪 What You'll Learn

### 🧲 Flexbox
| Concept | Description |
|---------|-------------|
| `display: flex` | Turn any container into a flex container |
| `flex-direction` | Row, column, or reverse |
| `justify-content` | Align items on the main axis |
| `align-items` | Align items on the cross axis |
| Live controls | Change properties and see boxes rearrange instantly |

### 🧩 Grid
| Concept | Description |
|---------|-------------|
| `display: grid` | Turn any container into a grid container |
| `grid-template-columns` | Define column structure |
| `grid-template-rows` | Define row structure |
| `gap` | Control spacing between items |
| Live controls | Adjust columns/rows and watch the grid adapt |
